# JoWell健身 · 抖音小程序发布前自检清单

> 适用：`src/douyin`（小程序，16 个页面）+ `src/api`（自建后端，`https://gym.jowellpet.xin`）
> 最后更新：2026-11-09 · API 镜像 `tt64-20261109`
> 新增模块部署提醒：`api/Dockerfile` 是**显式列文件名 COPY**，每次新增 `src/api/*.js` 都要同步那一行，否则线上容器起不来（502）。

## 一、逐页自检（真机，按顺序点）

### 首页
- [ ] 抬头 JOWELL / 名字 / 日期
- [ ] 今日印章有部位字；休息日显示「休」；练完有「已完成」圆章
- [ ] 「本周 N 次 / 连续 N 周 / 最近训练」有数字
- [ ] 周条：今天黑点、练过的日子红点、`‹ ›` 能翻周
- [ ] 「上周 / 总量」有数字
- [ ] 底部入口：我的计划 / 随便练 / 动作库 / 历史 / 统计 / 设置

### 动作库
- [ ] 「动作 5632 个动作」；卡片 / 列表切换；按肌肉可进
- [ ] 三排筛选（部位 / 类型 / 器械）点选后结果变化
- [ ] 搜「卧推」有结果；搜「卧推推」出现「没有精确匹配，这些比较接近」
- [ ] 专题按部位折叠，展开是横排（不能竖排）
- [ ] 教练讲解：57 条；20001–20003 显示正经标题；点开是讲解正文
- [ ] 「看原视频」能跳抖音（或提示已复制链接）
- [ ] 收藏 ★ 置顶；「计划」能把动作加进计划
- [ ] 器械档案横幅：勾了器械后开横幅，动作数量减少

### 动作详情
- [ ] 视频能播（网络 mp4 优先，失败退内嵌 base64）
- [ ] 部位 / 器械 / 英文名 / 要领齐全
- [ ] 关掉「动作示范动画」后只剩静图，并显示「点这里打开」

### 训练面板（本轮新增项最多，重点验）
- [ ] 进来自动带出今天的计划；休息日进「随便练」
- [ ] 完成一组 → 休息倒计时 → 到点震动 + 叮
- [ ] 余力 RIR 选 2 → 显示 `RPE 8`；记录后统计页力竭感有数据
- [ ] 点数字能**直接输入**重量 / 次数（秒数制显示秒）
- [ ] 「递减组」重量掉 10% 并多记一组
- [ ] 「休息暂停」只倒计时 15 秒
- [ ] 「热身组」记一条不计入正式组
- [ ] 「备注」保存后历史里能看到
- [ ] 「杠铃片」按目标重量算出每边挂片；凑不齐会提示差多少
- [ ] 「动作菜单」：上移 / 下移 / 换动作 / **把刚记的组改成热身** / 删除动作
- [ ] 动作名旁显示「上次 2026-11-05：60×8 60×8」
- [ ] 「超集」把当前和下一个绑一起，交替不休息；标题旁红标「超集 · xxx」
- [ ] 「专注」进入全屏专注层：大号重量×次数 + 完成/撤销/加一组/下一个；能退出
- [ ] 秒数制动作（平板支撑）：单位显示「秒」，加减一次 ±5 秒
- [ ] 每边动作：标题旁红标「每边」；历史里显示「（每边）」
- [ ] 撤销一组后，服务端那条也撤掉（再进历史核对）
- [ ] 关掉小程序再进 → 「继续上次的训练 · 已记 N 组」

### 计划
- [ ] 周安排：点开某天能选计划
- [ ] 「载入新手」→ 推/拉/腿三套 + 周一三五
- [ ] 新建 / 改名 / 加动作 / 改组数次数 / 删动作 / 保存
- [ ] 计划备注能保存，列表显示 `4 个动作 · A 日：大重量低次数`
- [ ] 「复制」生成 X 副本；「减载」生成 `X · 减载`（重量 ×0.6、组数 −1）
- [ ] 「↑ ↓」调动作顺序
- [ ] 「连」= 超集标记变红（保存后训练时自动交替）
- [ ] 「固定 / 金字塔」（12-10-8-6）、「同重 / 重量递增」（每组 +2.5kg）
- [ ] 「按次 / 按秒」、「双边 / 每边」
- [ ] 「进阶」循环：关 → 线性（达标 +2.5kg）→ 双重（先加次数、次数满再加重量）
- [ ] **计划轮换**：选两套以上 →「循环：推 → 拉 → 腿 · 下次：推」；练完一场指针前进一格

### 历史
- [ ] 按周分组（本周 / 上周 / X月X日 那周）
- [ ] 搜索「胸」或「11-0」能过滤
- [ ] 展开看到每组重量×次数、热身组数、备注、秒数制「60 秒」
- [ ] 破纪录动作有红 `PR`；折叠行显示「N 项 PR」
- [ ] 删除后从列表消失；「+ 补录」能补过去某天

### 统计
- [ ] 4 周 / 12 周 / 一年 切换后标题数字跟着变
- [ ] 肌肉平衡、结构平衡（推/拉/腿/核心）
- [ ] 力量 1RM 前 6；每周肌群容量堆叠条
- [ ] 单动作进步：选动作出柱状
- [ ] 体重柱状 + 训练活动格子（12 周）
- [ ] 疲劳度三档颜色；力竭感分布有柱子
- [ ] 最近训练列表可点进历史

### 体重 / 体测 / 饮食（入口在统计页底部）
- [ ] 体重：记录、7 天/30 天变化、曲线、删除、目标体重（距目标还差 X）
- [ ] 体测：躯干/手臂/腿/其他四组折叠；填几项保存；历史显示最新与差值
- [ ] 饮食：热量/蛋白完成度、目标、近 7 天柱状与平均

### 设置
- [ ] 默认休息、休息暂停可改；开关保存后立刻生效
- [ ] 提示音关掉不响、震动关掉不震、示范动画关掉只剩静图
- [ ] 单位 kg/lb 切换有确认并换算；小数位、周一起始
- [ ] 器械档案：勾器械 + 保存
- [ ] 构建标记显示最新版本

## 二、审核相关（抖音提审容易被问的点）

- [ ] 名称、简介、截图与实际功能一致（不要写"AI 教练""医疗建议"）
- [ ] 隐私政策：只收集 openid + 用户自填训练数据，服务自建
- [ ] 不出现诊断/治疗/疗效承诺；要领只描述动作
- [ ] 无第三方品牌 logo / 收费引导 / 外链跳转诱导
- [ ] 所有页面无空白页、无 404 文案、无英文报错
- [ ] 服务器域名白名单：`request`、`downloadFile`、`uploadFile`（图片上传走 request+base64，但视频/图片下载需要 downloadFile）
- [ ] 未登录时给出可读中文提示

## 三、发布步骤

1. 开发者工具：清缓存 → 编译 → 真机预览走完上面清单
2. 上传 `1.0.0`，写版本说明（建议：训练记录、动作库、计划、统计、体测、饮食）
3. 提交审核（类目：体育健身 / 工具）
4. 通过后发布
5. 发布后：视频挂载（半屏面板）+ 企业号主页挂官网链接

## 四、已知平台限制（不是 bug）

| 网页有 | 小程序为什么没有 |
|---|---|
| 推送通知 / 训练日提醒 | 无 Web Push；订阅消息一次授权一条，不适合定时提醒 |
| 导出/导入备份文件 | 依赖浏览器文件系统 |
| 通行密钥（passkey） | 抖音内零输入登录，不需要 |
| 管理员后台 | 只在网页使用 |
| Health Connect / 安卓 App | 平台不存在 |
| 进度照片 / 健身房签到卡 | `tt.chooseImage` 在当前基础库/环境下直接失败，等图片选图能力可用再开 |
| 主题 / 语言切换 | 固定纸墨主题 + 简体中文 |
| 左右滑动切组、滑动手势 | 小程序改为按钮；滑动与页面滚动冲突 |
| 真正的底部 tabBar | 平台样式固定，会破坏纸墨风；首页底部文字入口代替 |
| 教练 AI 问答 | 产品决策：审核敏感 + 成本 |
