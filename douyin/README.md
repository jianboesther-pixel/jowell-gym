# JoWell健身 · 抖音小程序（demo）

半屏训练面板：**组 → 休息（刷抖音）→ 到点 → 下一组**。原生抖音小程序，没有 web-view、没有外链，所以不存在"引导跳出"的审核问题。

> 对外名：**JoWell健身**（主体：成都琢乐科技有限公司）。底层数据后续由 openGym 提供，两个名字不冲突：一个服务品牌，一个软件名。

这个目录是独立的，不影响 `frontend/` 的构建与部署。

## 现在能做什么

- 一份写死的训练（卧推 4 组、划船 3 组），动作名/重量/次数/组数都在；
- **完成这组** → 按动作自己的休息时长进入倒计时；
- 倒计时用 **`restEndsAt` 时间戳**，不是累加：面板被划走、小程序被挂起，回来按时间差校正；
- 到点整块切成"下一组"，并震动（真机；开发者工具里静默跳过）；
- **加一组**、**跳过休息**、**−30s / +30s** 调休息时长；
- **休息时直接改下一组的重量和次数**（`−/+` 步进），不用退回待完成状态；
- 待完成时也能改重量 ±2.5 kg、次数 ±1；
- 本动作做完 → 下一个动作；全部做完 → 收工，显示完成组数；
- 面板底部对齐，**全屏和半屏都能看**：从视频挂载进来时它就在下半屏，上半继续播视频。

## 怎么打开

1. 装 **抖音开发者工具**（电脑版）；
2. **导入项目**，目录选 `src/douyin`，项目名 `jowell-fitness`；
3. AppID 填你刚创建的 **JoWell健身** 的 AppID（仓库里留的是占位 `testappid`）；
4. 编译即可。真机预览用工具里的二维码，用你的抖音号扫（你是所有者，有权限）。

> 半屏形态只有从**视频挂载/直播挂载**进入才会出现；在开发者工具里是整页，所以布局做成"贴底面板"，两种形态都不别扭。

## 已经接上的（2026-11）

1. **登录**：`tt.login` → `POST /api/tt/login`（服务端用 AppID/AppSecret 换 openid）→ Bearer 令牌，零输入；
2. **绑定已有账号**：面板底部「已有账号？绑定」→ `POST /api/tt/bind`（名字 + 密码一次）→
   `db.ttLinks[openid] = uid`，临时账号自动清掉；
3. **今天的计划**：`GET /api/tt/today?lang=zh` → 动作名走中文库（`api/tt-names-zh.js`，由
   `scripts/build-tt-names.mjs` 从 `frontend/src/exercise-names/zh.js` 生成）；
4. **每组记录**：`POST /api/tt/set` 直接把这一组写进 `state.workouts` 里一条 `ttLive: true` 的记录，
   网页端历史立刻可见；离线时进本地队列，回到前台补发（服务端按组号去重）；
5. **结束**：`POST /api/tt/finish` 只是去掉 `ttLive` 标记（记录留着），网页端今日卡片随之从
   「进行中」变「已完成」；
6. **中断续练**：`GET /api/tt/draft` 把未结束的场次并回来，直接停在第一个没做完的动作；
7. **换动作**（器械被占）：`GET /api/tt/alternatives?ex=` 返回同部位、优先别的器械的替代动作，
   点一条就在面板里换掉；已记的组留在原动作上；
8. **撤销一组**：`POST /api/tt/undo` 同时撤草稿和 `ttLive` 记录里那一格，本地待发队列也删掉；
9. **自由训练**：面板底部「随便练」→ 搜动作（`GET /api/tt/exercises`）→ 直接开一场没有计划的训练，
   `exerciseDone` 里还能「加动作」继续添；
10. **动作示范**：点动作名 → `GET /api/tt/exercise?id=` → 示范图（同一台服务器的 `/exercise-media/`）
    + 部位/器械，旁边一个「换个动作」。

> 网页端首页卡片认得 `ttLive`：有它时显示「进行中」并跳到历史，不再催你点「开始」。

### 入口与屏幕形态（2026-11）

抖音决定形态，小程序只能适配：

| 入口 | 形态 | 首屏 |
|---|---|---|
| 视频 / 直播间挂载 | 半屏（高度由平台控制） | 训练面板 |
| 搜索、抖音主页、侧边栏、最近使用、分享 | 全屏 | 首页（今天练什么 → 开始） |

实现：`pages/home/index` 注册在最前；进来先量 `windowHeight / screenHeight`，小于 0.78
就 `redirectTo` 到面板（挂载场景），否则留在首页。首页的「开始训练」再 `navigateTo` 面板；
「随便练」带 `?free=1`，面板启动后直接打开动作搜索层。

## 合规前置（代码之外）

- 企业主体 + 运动健身类目；
- 小程序备案（2023 年起强制）；
- 服务器域名 HTTPS + ICP 备案，配进小程序后台的 request 合法域名；
- 面板内不得出现二维码、加微信、下载 App 等引导。
